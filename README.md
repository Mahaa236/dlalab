## Before running
- Download and extract the required datasets separately; datasets are not included.
- Update dataset paths to match your files.
- Install imported libraries in a compatible Python environment.
- These are educational baselines. Record the actual results from your run; outputs are not precomputed.
- Experiment 4's optional ABC-to-MIDI conversion requires `abc2midi`.
